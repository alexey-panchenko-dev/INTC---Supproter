# Каталог приложений и языки интерфейса

Каталог `/applications` одинаковый для всех вошедших пользователей. Карточка ведёт на официальную страницу скачивания в новой вкладке. В ней показаны логотип, название и стоимость. Описание плавно раскрывается вниз поверх карточек следующего ряда при наведении или фокусе с клавиатуры, без изменения позиций сетки. На сенсорных устройствах описание видно сразу; настройка уменьшения анимации учитывается.

Администратор добавляет, изменяет и удаляет приложения на этой же странице. Удаление требует подтверждения в карточке. Студент не видит управление, сервер также проверяет роль, статус аккаунта и Origin для каждой операции записи.

## API и хранение

- `GET /api/v1/applications` — общий каталог.
- `POST /api/v1/applications` — создание, HTTP 201.
- `PUT /api/v1/applications/{id}` — полная замена полей карточки.
- `DELETE /api/v1/applications/{id}` — удаление, HTTP 204.

Поля: `name`, `description`, `description_kk`, `url`, `logo_url`, `pricing`. Для новой или изменяемой карточки обязательны описания на обоих языках. Категории удалены из интерфейса и API. Прежние столбцы `subject` и `subject_kk` сохранены в БД для совместимости с применёнными миграциями; новые записи получают пустые значения, старые значения не используются. Название продукта не переводится. `pricing`: `free`, `freemium`, `paid`. URL поддерживает только HTTP/HTTPS без credentials. Для логотипа также допустим локальный путь `/logos/<имя файла>`; сервер не скачивает внешние изображения. При ошибке загрузки логотипа видны инициалы названия.

Миграция `0003` добавляет поля и восемь начальных приложений: Visual Studio Code, Zed, PyCharm, Oracle VirtualBox, Git, Python, DBeaver Community и Blender. Существующие записи сохраняются, совпадающие названия пропускаются. При откате схемы записи каталога сохраняются с русскими полями. Для запуска: `docker compose exec api alembic upgrade head` (при старте контейнера миграции выполняются автоматически).

## Языки

`client/src/shared/i18n/` содержит словарь интерфейса RU/KK, React-провайдер и кнопку RU/KZ. Переключение доступно в шапке и на странице авторизации, не сбрасывает формы и не перезагружает страницу. Выбор хранится в `localStorage` (`intc-language`), обновляет HTML `lang`, title и meta description. При недоступном storage переключение продолжает работать в текущей вкладке. Запасной Noto Sans содержит казахские буквы.

Переведены навигация, главная, вход и регистрация, ограничения доступа, расписание и его редактор, документы, каталог и его редактор, чат, пустые состояния и сообщения ошибок. Описания приложений хранятся на двух языках в PostgreSQL. Имена пользователей, названия предметов в ручном расписании и содержимое загруженных документов сохраняют язык исходных данных. Они не переводятся автоматически.

Чат принимает необязательный `language: "ru" | "kk"` (по умолчанию `ru`). Язык выбранного интерфейса передаётся в запросе; для `kk` модель получает указание отвечать на казахском. История уже полученных сообщений не переводится задним числом. Внешний AI-провайдер требует настройки ключа и не проверяется тестами сети.

## Общая сетка страницы

Верхняя плашка, панель управления и карточки используют общую ширину контейнера. У сеток задан один исходный столбец с нулевой минимальной шириной, чтобы содержимое не расширяло страницу. Карточки растягиваются до одинаковой высоты в пределах ряда; длинные названия переносятся. Раскрытие описания поверх следующего ряда не меняет положение карточек.

Общее количество приложений и порядковые номера карточек не отображаются.
