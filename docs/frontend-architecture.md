# Фронтенд: FSD и Tailwind CSS

```text
src/
  app/                       сборка приложения, маршруты, глобальные стили
  pages/                     home, auth, schedule, documents, applications, chat
  widgets/portal-layout/     общая оболочка и навигация
  features/access-guard/     доступ к закрытым разделам
  entities/                  типы урока, документа, конкурса, приложения и сессии
  shared/                    API-клиент, общие UI-компоненты, конфигурация
```

Зависимости идут вниз: `app → pages → widgets → features → entities → shared`. Слайсы одного слоя не импортируют друг друга. Внешние импорты слайса идут через его `index.ts`/`index.tsx`. В `shared` сегменты (`api`, `ui`, `lib`, `config`) импортируются напрямую, без общего barrel-файла. Псевдоним `@/` указывает на `src/`.

Верстка использует Tailwind CSS через официальный Vite-плагин. Токены темы и базовые стили находятся в `app/styles/index.css`; стили компонентов задаются утилитами Tailwind. Не складывайте компоненты, загрузку данных и маршруты в один файл.

`app/config/route-config.tsx` содержит типизированный массив `routeConfig: RouteObject[]`: главную, закрытые разделы и маршрут 404. `app/providers/router.ts` создаёт единственный экземпляр `createBrowserRouter(routeConfig)`, а `app/app.tsx` подключает его через `RouterProvider`. Новые страницы добавляются в конфигурацию маршрутов.

Закрытые страницы обёрнуты в `AccessGuard`. `SessionProvider` получает аккаунт через `/api/v1/auth/me`; `useAuth` предоставляет состояние загрузки, вход, выход и повторную проверку. HttpOnly-cookie передаётся серверу браузером. Флаг в localStorage не используется; API независимо проверяет сессию и статус в БД.

`pages/auth` содержит вход и регистрацию на `/auth` и `/auth?mode=register`. После регистрации открывается форма входа. Параметр `next` возвращает пользователя в исходный раздел после входа. В шапке отображаются данные аккаунта, кнопка выхода и переключатель RU/KZ. Каталог управляется администратором прямо на `/applications`; общая админ-панель и импорт расписания остаются задачами следующих этапов. Потоковый AI-чат подключён, для внешних ответов требуется ключ провайдера.

`shared/i18n` содержит RU/KK-словарь, контекст языка, провайдер и переключатель. Провайдер оборачивает сессию и роутер; страницы используют `useI18n()`. Исходные строки в состоянии ошибок и уведомлений сохраняются на русском, переводятся при отображении, поэтому смена языка обновляет уже видимые сообщения. Пользовательские данные автоматически не переводятся.

`features/edit-application` содержит двуязычную форму создания и изменения записи каталога. `pages/applications` собирает сетку, раскрытие описаний, подтверждение удаления и повторную загрузку каталога после сохранения. Описания на обоих языках обязательны при записи. Категории удалены из карточек, формы и API. Подробности API и поведения — в [документации каталога](application-catalog.md).

После объединения `plugins` в `master` главная и жизнь колледжа сохраняют JSX-структуру и классы вёрстки `master`, поверх которых подключён перевод. `pages/documents` включает PDF-документы, пользовательские разделы с материалами, конкурсы и формы записи; управление доступно администратору. `shared/i18n/college-messages.ts` содержит переводы интерфейса этих разделов. Заголовки и содержимое документов и конкурсов сохраняют язык исходных данных.

Общий API-клиент поддерживает JSON и `FormData`: для загрузки PDF заголовок Content-Type с multipart boundary задаёт браузер. Сохранены cookies сессии, обработка ошибок сети и отмена запросов.

## Форматирование

В `client`:

```powershell
npm run format
npm run format:check
npm run lint
npm run build
```

Prettier форматирует TS, TSX, CSS, JSON и Markdown; плагин Tailwind сортирует классы. Конфигурация хранится в `.prettierrc.json`. Длинные выражения и JSX раскладываются по строкам; длинные строки классов могут оставаться одной строкой по правилам Prettier.

В `api`, после установки `requirements-dev.txt`:

```powershell
python -m ruff format .
python -m ruff format --check .
python -m ruff check .
```

Ruff форматирует Python и проверяет импорты. Настройки лежат в `api/pyproject.toml`. В корне `.editorconfig` и `.vscode/settings.json` задают отступы, LF и форматирование при сохранении; установите рекомендованные расширения из `.vscode/extensions.json`.
