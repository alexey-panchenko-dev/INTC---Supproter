# Согласованные требования

- Название: INTC - Supporter. Команда: пять человек.
- Сейчас нужен каркас всех разделов; AI подключает сокомандник последним этапом.
- Роли: ученик и администратор. Гостю доступна только главная.
- Ученики самостоятельно создают аккаунты: фамилия, имя, почта, группа. Админ сверяет ученика со списком группы и может заблокировать аккаунт.
- Необходимость одобрения до первого доступа ещё не уточнена; текущий каркас авторизации остаётся заглушкой.
- Расписание загружается на конкретные даты картинкой или через Excel. Автоматическое чередование чётных и нечётных недель не требуется.
- Документы из открытых источников вручную загружает администратор.
- Языки продукта: русский и казахский. Полные переводы ещё не реализованы.
- Приложения: ссылки на официальные сайты.
- Фронт: React + TS, FSD, Tailwind CSS. Бэк: FastAPI, PostgreSQL в Docker.
- Форматирование: Prettier на фронте, Ruff на бэке.

1. Вход по паролю или одноразовому коду на почту?

3. Нужен образец Excel: формат колонок, группы, подгруппы, смены и замены. Как админ задаёт даты для изображения расписания?
4. Какие форматы документов нужны (PDF, DOCX, сканы), кто отвечает за актуальность и нужны ли OCR и хранение файлов?
5. Официальное название колледжа, настоящий логотип, визуальные референсы?
6. Платформы и фильтры каталога приложений?
