# Промпт для дизайна INTC Supporter

Скопируй текст ниже в инструмент для проектирования интерфейсов. Прикрепи референсы и настоящий логотип колледжа. Точный оттенок голубого возьми из логотипа; до его получения используй #4BB8EE как временный акцент. Реализация: React + TypeScript, FSD, Tailwind CSS.

---

Разработай UI/UX адаптивного студенческого портала INTC Supporter для IT-колледжа. Это ежедневный инструмент студентов: расписание, жизнь и инфраструктура колледжа, официальные документы, каталог учебных приложений и ИИ-помощник по документам колледжа.

Опирайся на приложенные референсы: изучи их композицию, плотность, типографику и навигацию. Создай самостоятельный интерфейс с похожим настроением. Используй приложенный логотип без изменения пропорций и цветов. Если вложений нет, не выдумывай фирменный логотип — обозначь место для него.

Стиль: современный, спокойный, удобный для ежедневного использования. Светлый фон, белые поверхности, тёмный читаемый текст. Голубой из логотипа — основной акцент для действий, активных состояний и выделения. Не заливай весь экран голубым. Используй ясную типографику с кириллицей, сетку с шагом 8 px, умеренные скругления, тонкие границы и сдержанные тени. Минимизируй декоративный шум; расписание должно читаться с первого взгляда.

Подготовь связанные экраны:
1. Главная: ближайшие пары, быстрый доступ к документам и каталогу приложений, объявления колледжа и вход в чат.
2. Расписание: выбор группы, день/неделя, переключение дат, кнопка «Сегодня», время пары, предмет, преподаватель, аудитория, тип занятия, замены. На телефоне — вертикальная повестка дня.
3. Жизнь колледжа: документы по категориям с поиском; сведения об отделениях, кабинетах, библиотеке, столовой и контактах. Экран документа с датой обновления и скачиванием.
4. ИИ-чат: список диалогов, примеры вопросов, поле ввода, ответ с кликабельными источниками и названиями документов. Покажи состояния поиска ответа, отсутствия данных и ошибки. Помощник отвечает только на основании доступных материалов и признаёт отсутствие ответа.
5. Каталог приложений: поиск, фильтры по предмету, платформе и назначению, карточка приложения, описание, инструкция и ссылка на официальный сайт.
6. Регистрация: ФИО, email, группа, пароль; после отправки — отдельный экран «Ожидает подтверждения». Отдельно вход, ошибка и отклонённая заявка с понятным следующим шагом. Самостоятельная регистрация студента; подтверждение администратором после сверки со списком колледжа.
7. Кабинет студента: группа и статус аккаунта. Регистрация содержит отдельные поля «Фамилия», «Имя», «Почта», «Группа». Гостю доступна только главная страница; закрытые разделы показывают приглашение войти. Роли только ученик и администратор. Администратор может блокировать аккаунт после сверки с группой.
8. Админ-панель: очередь заявок, просмотр данных, подтверждение и отклонение; управление документами, расписанием и каталогом приложений. Для документов — статус обработки ИИ и ошибка индексации.

Навигация: на десктопе боковое меню; на телефоне компактная навигация с доступом к основным разделам. Подготовь русский и казахский варианты интерфейса. Каталог приложений содержит ссылки на официальные сайты. Для администратора предусмотрены ручная загрузка документов и загрузка расписания изображением либо импорт Excel с предварительным просмотром.

Создай desktop 1440 px и mobile 390 px, компоненты, токены цветов и типографики, состояния hover/focus/disabled/loading/error/empty/success. Обеспечь контраст WCAG AA, видимый фокус, подписи полей и зоны касания от 44 px. Передай макеты так, чтобы их можно было реализовать на React + TypeScript. Демонстрационные имена, группы и расписание обозначай как примеры. Не обещай, что ИИ знает ответ на любой вопрос.
