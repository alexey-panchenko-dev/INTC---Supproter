# INTC - Supporter: frontend

React + TypeScript + Vite + Tailwind CSS. Структура FSD описана в `../docs/frontend-architecture.md`.

- `npm ci` — установка зависимостей.
- `npm run dev` — сервер разработки.
- `npm run build` — проверка TypeScript и сборка.
- `npm run format` — форматирование Prettier и сортировка классов Tailwind.
- `npm run format:check` — проверка форматирования.
- `npm run lint` — проверка Oxlint.

API проксируется через Vite. Полная инструкция запуска Docker — в корневом README.
